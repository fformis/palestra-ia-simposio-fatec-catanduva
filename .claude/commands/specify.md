Crie uma nova feature SDD a partir de: $ARGUMENTS

1. Leia `.claude/CONSTITUTION.md` e liste `specs/` para definir o próximo número `NNN` e um slug curto.
2. Crie `specs/NNN-slug/spec.md` a partir de `specs/_templates/spec.md`.
3. Descreva apenas O QUÊ e POR QUÊ — nada de stack ou implementação.
4. Marque lacunas como `[NEEDS CLARIFICATION]` e liste-as ao final para o usuário.
